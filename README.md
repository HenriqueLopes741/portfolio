# Portfólio · Henrique Lopes

Site pessoal com meus projetos, minha experiência em engenharia de dados e meu currículo.

**Acesse:** [henriquelopes741.github.io/portfolio](https://henriquelopes741.github.io/portfolio)

## Tecnologias

HTML, CSS e JavaScript puro, sem frameworks nem build. Hospedado no GitHub Pages.

## Estrutura

```
index.html                    conteúdo do site
style.css                     estilos (tema claro e escuro)
script.js                     tema, filtro de projetos e repositórios via API do GitHub
foto.jpg                      foto de perfil
curriculo-henrique-lopes.pdf  currículo para download
```

## Rodar localmente

```bash
git clone https://github.com/HenriqueLopes741/portfolio.git
cd portfolio
```

Abra o `index.html` no navegador.
